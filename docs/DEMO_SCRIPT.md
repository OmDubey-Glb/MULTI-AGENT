# Demo script (planned)

1. Open the AgentOps dashboard.
2. Submit a fictional NovaMart request for Personal profile and Email address.
3. Verify using the local demo inbox (never a real delivery channel).
4. Watch Intake hand off the scoped request to Discovery.
5. Show the Deletion Request Agent submitting an authorized request to the NovaMart simulator.
6. Demonstrate independent verification, a bounded retry, and a human ticket for immutable backups.
7. Show the privacy-minimized audit trail and monitoring status.

All people and records used in the demo must be synthetic.
